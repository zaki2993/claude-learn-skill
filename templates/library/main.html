How this works
  1. This page is the start of everything. Bookmark it.
  2. To add material, run claude in this folder, then /learn plus what you want, in plain words: 
    /learn linear equations
/learn next lesson on react hooks
/learn more hard problems on vectors
/learn I forgot how SQL joins work
    It always asks how deep to go: quick, normal, deep, or master.
  3. Every topic has lessons, exercises (guided, practice, real-world, boss), a review for when you've forgotten, and a cheatsheet.
  4. Hard coding exercises are real files in each topic's practice/ folder. Run them in your terminal.
  5. Everything here works without Claude.
