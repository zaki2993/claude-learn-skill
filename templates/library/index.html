Your library

Pick up where you left off, refresh what's fading, or search anything you've learned.

    How this works
    1. In a terminal inside this folder, run claude, then /learn plus what you want, in plain words: 
      /learn linear equations
/learn next lesson on react hooks
/learn more hard problems on vectors
/learn I forgot how SQL joins work
      It always asks how deep to go: quick, normal, deep, or master.
    2. Every topic has lessons, exercises (guided, practice, real-world, boss), a comeback review for when you've forgotten, and a cheatsheet.
    3. Hard coding exercises are real files in the topic's practice/ folder. Run them in your terminal.
    4. Everything here works without Claude. Ask Claude when you want new material or you're stuck.
