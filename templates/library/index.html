    1. One command: in your terminal, inside this folder, run claude and type /learn + what you want, in plain words: 
      /learn linear equations
/learn next lesson on react hooks
/learn more hard problems on vectors
/learn I forgot how SQL joins work
/learn update the python loops cheatsheet
    2. Each topic has 4 kinds of pages:
      • 📖 Lessons: problem → picture → how it works → examples → solve it → cheat card
      • ✍️ Exercises: 🧩 guided → 🟢 practice → 🟡 real-world → 🔴 boss. Answers are checked right on the page.
      • 🔁 Comeback: forgot everything? Read the key points in 2 minutes, then go straight to hard problems.
      • 📌 Cheatsheet: every cheat card in one page, for quick lookups.
    3. Hard exercises also come as real files in the topic's practice/ folder, to run in your terminal.
    4. Everything works without Claude. Open this page in your browser anytime. Ask Claude only when you want new stuff or you're stuck.
